# Tmux 

Gestionnaire de terminal

## Configuration 

Le fichier est placer dans `~/.tmux.conf`


## Keymap 

| Key | Fonction |
| --- | ---- |
| `C c` | Tmux capture la saisis pour les commandes | 
| `\|` | Split horizontale | 
| `-` | Split verticale | 
| `Alt + fleche` | Changement de panel |
| `x` | Fermer le panel |
